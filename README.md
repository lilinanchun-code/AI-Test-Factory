# AI Test Factory

An AI-powered automotive testing workflow system.

## What it does

This system converts natural language input into:

- Test Points
- Test Cases
- Bug Reports

## Example

Input:
"中控屏开机偶发黑屏"

Output:

- test_points.md
- test_cases.md
- bug_report.md

## Purpose

To simulate a real automotive testing workflow using AI.
