# AI Test Factory

AI Test Factory is a structured automotive electronics testing asset generation system.

The goal of this project is not only to generate test cases,
but to build a reusable workflow for automotive testing teams.

---

# Core Workflow

Natural Language Input
↓
OpenClaw Dispatch
↓
Structured Prompt Generation
↓
Test Asset Production
↓
GitHub Knowledge Base

---

# Current Supported Domains

- IVI
- Cluster
- Camera
- Power

---

# Generated Outputs

Each scenario can automatically generate:

- Test Points
- Test Cases
- Bug Reports

---

# Example Scenarios

- IVI black screen during boot
- Bluetooth playback interruption
- CarPlay no audio
- OTA upgrade lag
- Reverse camera abnormal display
- Cluster speed delay
- Low voltage boot black screen

---

# Project Goal

Build a scalable AI-assisted automotive testing workflow
for interview demonstrations, knowledge accumulation,
and future team collaboration.
