# Automotive Testing Industry Alignment

AI-Test-Factory is designed around automotive electronics testing documentation workflows.

## Relevant Domains

- IVI / infotainment
- Instrument Cluster
- Rear View Camera
- Bluetooth audio
- Power management
- Intelligent cockpit scenarios

## Workflow Alignment

The project supports early-stage testing work:

1. scenario intake
2. scenario parsing
3. test point drafting
4. test case drafting
5. bug report drafting
6. review and reuse

## Standards Awareness

The project is not claiming certification or compliance. It borrows process thinking from automotive software quality practices:

- structured requirements and test artifacts
- traceable workflow outputs
- reviewable evidence
- repeatable execution
- issue lifecycle awareness

In an enterprise environment, the project should be adapted to the company's approved process, tools, and data security policy.
