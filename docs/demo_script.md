# AI Test Factory｜演示讲稿（Demo Script）

---

# 1. 项目背景

传统测试工作中：

- 测试点整理耗时
- 测试用例重复率高
- 缺陷报告依赖经验
- 文档结构不统一

因此我尝试利用 AI + Workflow 的方式，
构建一个“测试辅助生产系统”。

目标不是替代测试人员。

而是：

提高测试资产生成效率，
提升结构化协作能力。

---

# 2. 系统核心思路

系统流程：

输入问题
→ 自动解析
→ Prompt 构建
→ AI 生成
→ 输出测试资产

目前系统可自动生成：

- test_points.md
- test_cases.md
- bug_report.md

---

# 3. 演示案例

示例输入：

仪表盘重启后时间丢失
模块：Cluster
场景：整车断电重启

系统会自动：

1. 提取测试主题
2. 分析模块信息
3. 构建测试 Prompt
4. 生成测试点
5. 生成测试用例
6. 生成缺陷报告

最终输出结构化 Markdown 文档。

---

# 4. 当前系统结构

目前系统主要包括：

## 输入层

- Feishu
- iMessage
- 文本输入

---

## 处理层

- Shell Workflow
- Prompt Builder
- Output Generator

---

## 输出层

- Markdown 文档
- 测试资产归档
- 案例沉淀

---

# 5. 我重点关注的方向

相比“单次生成”。

我更关注：

- 结构化
- 可复用
- 工程协作
- 自动化流程
- 测试资产沉淀

因为我认为：

AI 真正的价值，
不是聊天。

而是参与生产流程。
