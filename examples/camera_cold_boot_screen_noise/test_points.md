# 测试点清单：低温启动倒车影像花屏

生成时间：2026-05-15 19:42:44

## 一、测试目标
验证 Camera 模块在“冬季冷启动”场景下，是否能保持功能状态一致、数据正确恢复，并避免出现用户可感知异常。

## 二、核心风险
1. 断电后关键数据未正确持久化
2. 重启后系统时间、配置或状态恢复异常
3. 电源管理流程与模块初始化时序不一致
4. RTC、车机时间源、CAN 时间同步存在冲突
5. 异常发生后缺少提示、恢复或日志记录机制

## 三、测试点
| 编号 | 测试点 | 关注内容 | 优先级 |
|---|---|---|---|
| TP_001 | 正常断电重启 | 重启后时间是否保持正确 | P0 |
| TP_002 | 长时间断电 | 断电一段时间后时间是否丢失 | P0 |
| TP_003 | 快速断电重启 | 短时间断电再上电后是否异常 | P1 |
| TP_004 | 多轮循环测试 | 多次整车断电重启后是否稳定 | P0 |
| TP_005 | 时间同步测试 | RTC、车机系统时间、网络/CAN 时间是否一致 | P1 |
| TP_006 | 日志检查 | 检查电源、时间同步、模块初始化相关日志 | P1 |
