# Examples

This directory contains scenario-based testing asset examples generated by AI Test Factory.

Each example is designed as a small testing asset package, including:

- input scenario
- test points
- test cases
- bug report

---

## Purpose

The purpose of examples is not only to show generated content, but to demonstrate how testing problems can be transformed into reusable engineering assets.
