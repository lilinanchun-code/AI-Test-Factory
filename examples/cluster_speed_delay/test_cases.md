# 测试用例：车速显示延迟

生成时间：2026-05-15 19:43:22

## TC_CLUSTER_001 正常断电重启时间保持验证
- 测试目标：验证车辆整车断电重启后，Cluster 模块时间显示是否保持正确
- 前置条件：车辆时间已设置正确，系统处于正常工作状态
- 操作步骤：
  1. 确认仪表盘当前显示时间正确
  2. 执行整车断电
  3. 等待车辆完全下电
  4. 重新上电启动车辆
  5. 观察仪表盘时间显示
- 预期结果：仪表盘时间应保持正确，不应恢复默认时间或出现明显偏差
- 优先级：P0

## TC_CLUSTER_002 长时间断电后时间恢复测试
- 测试目标：验证车辆长时间断电后，时间信息是否仍可正确恢复
- 前置条件：车辆时间已设置正确
- 操作步骤：
  1. 记录断电前仪表盘时间
  2. 执行整车断电并保持一段时间
  3. 重新上电
  4. 检查仪表盘时间是否正确
- 预期结果：时间不应丢失；如依赖同步源，应在合理时间内完成校准
- 优先级：P0

## TC_CLUSTER_003 快速断电重启异常测试
- 测试目标：验证快速断电/上电场景下时间显示是否异常
- 前置条件：车辆处于可测试状态
- 操作步骤：
  1. 设置并确认当前时间
  2. 执行整车断电
  3. 间隔 3-5 秒后重新上电
  4. 观察仪表盘时间显示
- 预期结果：时间显示应正确，不应出现归零、跳变、默认值或长时间不同步
- 优先级：P1

## TC_CLUSTER_004 多轮断电重启稳定性测试
- 测试目标：验证多轮整车断电重启后时间显示稳定性
- 前置条件：车辆状态正常，时间已设置正确
- 操作步骤：
  1. 执行整车断电
  2. 等待车辆完全下电
  3. 重新上电
  4. 检查仪表盘时间
  5. 重复以上步骤 30-50 次
- 预期结果：每轮测试后时间均应正确，不应偶发丢失
- 优先级：P0
