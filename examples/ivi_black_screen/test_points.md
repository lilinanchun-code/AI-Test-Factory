# 测试点清单：中控屏开机偶发黑屏

生成时间：2026-04-24 20:40:47

## 一、测试目标
验证 IVI 中控屏在电源循环开机、低电压、快速上下电等场景下，是否能稳定完成启动、显示初始化和主界面加载。

## 二、核心风险
1. 上电时序异常导致显示屏未初始化
2. 系统启动过程中服务加载失败
3. 低电压或电压波动导致偶发黑屏
4. CAN/车身状态信号异常导致屏幕状态判断错误
5. 黑屏后无自动恢复机制

## 三、测试点
| 编号 | 测试点 | 关注内容 | 优先级 |
|---|---|---|---|
| TP_001 | 正常冷启动 | Logo、背光、主界面是否正常显示 | P0 |
| TP_002 | 连续电源循环 | 多次 ACC/OFF/ON 后是否偶发黑屏 | P0 |
| TP_003 | 低电压启动 | 9V-11V 电压范围内启动稳定性 | P0 |
| TP_004 | 快速上下电 | 短时间重复上下电是否异常 | P1 |
| TP_005 | 黑屏恢复 | 重启、休眠唤醒后是否恢复 | P0 |
| TP_006 | 日志检查 | 系统日志、显示驱动日志、启动日志 | P1 |
