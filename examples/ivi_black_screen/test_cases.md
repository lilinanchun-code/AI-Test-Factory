# 测试用例：中控屏开机偶发黑屏

生成时间：2026-04-24 20:40:47

## TC_IVI_001 正常冷启动显示验证
- 测试目标：验证车辆正常上电后，中控屏是否能完成启动并进入主界面
- 前置条件：车辆处于 OFF 状态，蓄电池电压 12V-14V
- 操作步骤：
  1. 将车辆电源切换至 ON/ACC
  2. 观察中控屏背光、Logo、启动动画
  3. 等待系统进入主界面
- 预期结果：中控屏应正常点亮，显示启动 Logo，并在规定时间内进入主界面
- 优先级：P0

## TC_IVI_002 连续电源循环稳定性测试
- 测试目标：验证多次上下电后是否出现偶发黑屏
- 前置条件：车辆电源系统正常，中控屏无历史故障
- 操作步骤：
  1. 执行 ACC ON
  2. 等待中控屏进入主界面
  3. 执行 ACC OFF，等待系统休眠
  4. 重复以上步骤 50 次
- 预期结果：每次启动中控屏均能正常显示，不应出现黑屏、卡死、无背光等现象
- 优先级：P0

## TC_IVI_003 低电压启动测试
- 测试目标：验证低电压环境下中控屏启动稳定性
- 前置条件：使用可调电源或低电压模拟环境
- 操作步骤：
  1. 将供电电压调整至 9V-11V 区间
  2. 执行车辆上电
  3. 观察中控屏显示状态
  4. 记录是否出现黑屏、重启、启动超时
- 预期结果：系统应在允许电压范围内正常启动；若无法启动，应有明确保护或恢复机制
- 优先级：P0

## TC_IVI_004 快速上下电异常恢复测试
- 测试目标：验证快速上下电场景下系统是否异常
- 前置条件：车辆处于可测试状态
- 操作步骤：
  1. 执行 ACC ON
  2. 中控屏启动过程中立即 ACC OFF
  3. 间隔 3-5 秒后再次 ACC ON
  4. 观察中控屏是否恢复正常
- 预期结果：中控屏不应长期黑屏；再次上电后应能恢复显示
- 优先级：P1
