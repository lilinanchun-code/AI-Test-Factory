# 缺陷报告：中控屏开机偶发黑屏

生成时间：2026-04-24 20:40:47

## Bug编号
BUG_IVI_BOOT_001

## Bug标题
中控屏在电源循环开机后偶发黑屏

## 所属模块
IVI / Display / Boot

## 测试阶段
系统功能测试 / 稳定性测试

## 问题描述
在车辆进行多次电源循环开机测试时，中控屏偶发无法正常点亮，表现为黑屏或无启动画面。车辆其他基础功能未见明显异常。

## 前置条件
- 车辆电源状态正常
- 中控屏软件版本为当前测试版本
- 测试场景为 ACC/OFF/ON 电源循环

## 复现步骤
1. 车辆处于 OFF 状态
2. 切换至 ACC/ON
3. 等待中控屏启动完成
4. 切换至 OFF 并等待系统休眠
5. 重复以上操作多次

## 实际结果
部分轮次中控屏未正常显示启动 Logo 或主界面，出现黑屏现象。

## 预期结果
每次上电后中控屏均应正常点亮并进入主界面。

## 复现概率
偶发，需进一步统计，例如 50 次循环中出现 1-2 次。

## 严重程度
Major

## 优先级
P0

## 影响评估
该问题影响用户启动车辆后的信息显示与交互体验，可能影响倒车影像、导航、多媒体等功能使用。

## 初步分析
可能与上电时序、显示驱动初始化、系统服务启动顺序、电压波动或休眠唤醒状态恢复有关。当前不直接判定根因，建议结合日志进一步分析。

## 建议跟进
1. 抓取黑屏发生时系统日志
2. 检查显示驱动初始化日志
3. 对比正常启动与异常启动时序
4. 增加低电压和快速上下电场景复测
5. 联合软件、硬件、电源相关人员定位
